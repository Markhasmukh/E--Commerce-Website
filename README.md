# E-Commerce Website

This is an E-Commerce Website built using HTML5 and CSS3. It is designed to showcase products, manage the shopping cart, and provide a smooth browsing experience with responsive design.

* Features
Home Page: Displays a list of featured products with images and basic descriptions.
Product Pages: Users can view detailed information for each product.
Shopping Cart: Users can add products to their cart and view their selections.
Responsive Design: The website is fully responsive using CSS media queries to adjust to various screen sizes.
User-Friendly Interface: Simple, easy-to-navigate design for a seamless shopping experience.
* Tech Stack
Frontend: HTML5, CSS3
Responsive Design: CSS media queries for mobile compatibility
Features Implemented: Product listing, shopping cart, and basic layout styling
Installation
Clone the repository to your local machine:

git clone https://github.com/Markhasmukh/E--Commerce-Website.git
Open the index.html file in your browser to view the website.

Usage
Browse the homepage to explore featured products.
Click on individual products to view more details.
Add products to your shopping cart by clicking "Add to Cart."
View your cart and navigate through the available options.
